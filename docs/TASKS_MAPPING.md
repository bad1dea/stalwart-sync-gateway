# Tasks Mapping

ActiveSync Tasks should map to JSCalendar task/todo semantics where Stalwart exposes them through JMAP Calendar support.

Fields:

- title
- description/body
- due/start dates
- completed state/time
- importance
- recurrence
- reminders
- categories

Tasks must not be represented as email unless current Stalwart capabilities prove there is no viable JMAP calendar/task representation.
